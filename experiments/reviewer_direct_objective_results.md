# 冻结 DARS 的原始时延目标直接求解对照

> 2026-10-31 有效性更正：旧低/高负载两批的到达率在 reset 时被覆盖，实际均为基础0.9/0.1，下面旧负载表不能作为低/高负载证据。基础和20 kJ批次不受此问题影响。评估器已修复，两批各50回合重测已完成；目录为 reviewer_direct_objective_load_low_fixed_20261031 和 reviewer_direct_objective_load_high_fixed_20261031。有效状态为2260/2260和2375/2377，gap均值/P95分别为0.65931%/3.16703%、0.46129%/1.79750%。新完整汇总见 paper/revision_20261031/原始目标负载对照修复结果.md；下面旧记录保留供追溯，独立求解器最优性核验仍待。

## 设计与范围

固定已训练的 `per_sac_cvx` seed 42 检查点，不训练或更新策略。基础测试使用独立种子 200000–200099；任务到达分布为热簇/冷簇 0.90/0.10，电池容量和初始能量均为 40 kJ。策略按原环境动作推进每个回合，参考解仅旁路计算、不写回环境。

每个接受状态固定任务、UAV/UE 位置、信道增益、关联、安全层最终卸载比例和逐 UAV 剩余计算能量预算。CF 使用环境真实闭式 CPU/带宽分配；OPT 只改变 CPU/带宽，按 UAV 分组数值最小化

\[
J=\sum_i \frac{\max\{T_i^{\mathrm{loc}},T_i^{\mathrm{edge}}\}}{T_i^{\mathrm{base}}},
\]

并施加同一 CPU、带宽总量上限和逐 UAV 计算能量约束。优化写成 epigraph 凸问题，以 SciPy SLSQP 求解；按各用户基准时延归一化变量。成功解须通过求解器状态、CPU/带宽/能量/epigraph 残差检查，且目标不高于 CF。失败参考解不进入 gap 和 SLRR 统计。没有卸载用户但有活跃任务的状态按解析平凡解处理；被环境拒绝的动作排除。

逐状态结果保存完整配对快照：活跃掩码、任务大小、动作前后 UAV 坐标、UE 坐标、完整信道增益矩阵、安全层缩放前后的卸载比例、关联、预算，以及 CF/OPT CPU、带宽和时延向量。模型参数评估前后摘要一致。

## 基础测试结果

gap 定义为 \((J_{CF}-J_{OPT})/J_{OPT}\times100\%\)，仅对活跃任务、正分母且参考解有效的状态统计。SLRR 差值是有效状态上的活跃用户平均 rho 增益；固定时域差值沿仓库的每回合 SLRR 口径计算。

| 指标 | 结果 |
|---|---:|
| 独立测试种子 / 请求回合 | 200000–200099 / 100 |
| 接受的活跃状态 / 有效参考状态 | 4,974 / 4,973（99.980%） |
| 原始目标相对差距，均值 / P95 | 0.8465% / 3.1190% |
| 平均 SLRR 增益（活跃用户均值） | 0.004298 |
| 固定时域平均 SLRR 增益 | 0.004297（95 个完整、无拒绝且参考有效的回合） |
| CF 闭式分配平均耗时 | 0.1216 ms/状态（P95 0.1532 ms） |
| OPT 建模加 SLSQP 平均耗时 | 3.5089 ms/状态（P95 5.9219 ms） |
| 数值求解成功率 | 状态 4,973/4,974（99.980%）；UAV 子问题 9,476/9,477（99.989%） |
| 最大约束残差 | CPU 1.27e−12、带宽 1.86e−13（容量比例）；能量超额 0 J；归一化 epigraph 9.04e−10 |
| CF 延迟公式复算误差 | 最大 1.78e−15 s |

因此基础分布上，CF 平均约快 28.9 倍；直接目标求解的相对差距均值低于 1%，但尾部 P95 约 3.12%，不能表述成等价或全局最优。每个状态均纳入统计，没有按边缘分支是否较慢筛选；边缘分支占优比例仅作为描述统计，基础有效状态的逐状态比例均值约 77.7%。

|---|---|---:|---:|---:|---:|---:|

| 高负载 | 热/冷到达率 0.98/0.45；2,478/2,479 | 0.8578% / 3.2746% | 0.004331 | 0.1215 / 3.5755 ms | 99.96% 状态 | 45/50 |
| 低电量 | 初始能量 20 kJ，容量仍为 40 kJ；8,659/8,666 | 0.5972% / 2.6980% | 0.003430 | 0.1105 / 2.7265 ms | 99.92% 状态 | 0/500 |

低/高负载种子分别为 210000–210049、220000–220049；低电量种子为 230000–230499。各场景都使用冻结策略和同一配对求解器，单独统计，不合并进基础分布。两组负载的能量超额为 0；500 种子低电量批次的最大能量超额为 2.21e−10 J（数值精度量级）。最大归一化 epigraph 残差分别为 4.76e−10、5.07e−10、9.04e−10。

低电量扩展使用 500 个种子；全部回合均因环境能量安全检查拒绝动作而提前终止，因此没有完整回合 SLRR 结果。终止前 8,666 个接受状态中有 45 个触发卸载安全层，比例为 0.519%；这 45 个状态的总卸载比例平均缩小 29.85%，最大缩小 95.98%，最小 UAV 缩放系数为 0.00678。该投影子集全部有有效参考解，其 gap 均值/P95 为 0.253%/1.770%，边缘分支占优的逐状态比例均值为 61.69%；主要低电量 gap 仍使用全部 8,659 个有效状态，不按分支筛选。安全层确实改变了部分状态的分支关系，但该策略无法完成完整时域，不能据此宣称低电量下完整回合收益可接受。

## 解释边界

数值参考解只是在给定 UAV/UE 位置、任务、信道、关联、安全层卸载比例和该步能量预算后，对 CPU/带宽资源子问题的参考最优值；它不是轨迹、关联、卸载比例联合优化的全局最优值。基础批次有 1 个 UAV 子问题未通过求解/残差验收，4 次环境动作被拒绝；这些状态未被当作有效参考解。其余有效解均满足报告的残差和能量检查。

证据支持的结论是：在已测基础及负载场景中，闭式资源分配相对原始 SLRR 时延目标的平均损失较小且计算明显更快，当前结果不支持为这条意见重训全部模型；但应把论文声明收紧为“闭式解是特定代理子问题的最优解”，不能声称它等价求解原始最大时延目标或令整个分解全局最优。低电量策略的提前终止应作为单独限制报告。
